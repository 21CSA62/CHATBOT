🧑‍💻🤖The project structure includes an index.html file located at the root level. Inside the project, there is a static folder, which contains two subfolders: css and scripts.
Within the css folder, there are the following files: chat.css, home.css, link.css, and style.css.
In the scripts folder, you will find chat.js and response.js.
